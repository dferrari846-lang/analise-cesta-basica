# 🛒 Análise de Cesta Básica (Flowgorithm)

Algoritmo desenvolvido em **Flowgorithm** para realizar o cálculo da variação percentual de preços de três produtos da cesta básica entre o mês anterior e o mês atual. O sistema gera um relatório detalhado indicando a tendência de comportamento de cada item (Aumento, Queda ou Estável).

---

## ⚙️ Funcionalidades
* **Cadastro Interativo:** Entrada dinâmica para o nome do produto, valor no mês anterior e valor no mês atual.
* **Cálculo Automático:** Aplicação de fórmula matemática para obtenção da variação percentual exata.
* **Estrutura Condicional:** Identificação inteligente da situação de mercado (identificando se houve alta, baixa ou estabilidade nos preços).
* **Relatório Formatado:** Exibição consolidada no terminal com um resumo claro de todos os produtos analisados.

---

## 🛠️ Tecnologias Utilizadas
* **[Flowgorithm](http://www.flowgorithm.org/):** Ambiente de programação visual baseado em fluxogramas utilizado para a concepção e teste da lógica.

---

## 🚀 Como Executar o Projeto

1. Baixe e instale o [Flowgorithm](http://www.flowgorithm.org/) em seu computador.
2. Faça o download do arquivo do fluxograma presente neste repositório (`analise_cesta_basica.fprg`).
3. Abra o arquivo diretamente no Flowgorithm.
4. Clique no botão **Executar** (ícone de "Play" verde na barra superior) para testar o algoritmo interativamente.
